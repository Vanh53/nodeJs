# Checklists học và làm project

## JavaScript base

- [ ] Phân biệt primitive và reference.
- [ ] Giải thích stack/heap bằng ví dụ object mutation.
- [ ] Dùng `let`/`const`, không dùng `var`.
- [ ] Biết khi nào dùng `??` thay vì `||`.
- [ ] Viết được closure đơn giản.
- [ ] Dùng `map`, `filter`, `reduce`, `find`, `flatMap`.

## JavaScript advanced

- [ ] Giải thích được call stack.
- [ ] Dự đoán output event loop cơ bản.
- [ ] Dùng Promise và async/await đúng.
- [ ] Xử lý async error bằng `try/catch`.
- [ ] Hiểu `this`, `bind`, `call`, `apply`.
- [ ] Tạo custom error class.

## TypeScript

- [ ] Dùng `unknown` và narrowing.
- [ ] Chọn `type` hoặc `interface` hợp lý.
- [ ] Viết generic repository.
- [ ] Dùng `Partial`, `Pick`, `Omit`, `Record`.
- [ ] Dùng discriminated union và exhaustive check.

## Node.js

- [ ] Phân biệt CommonJS và ES Modules.
- [ ] Dùng `process`, `path`, `fs/promises`.
- [ ] Tạo HTTP server raw.
- [ ] Dùng EventEmitter cho pub/sub đơn giản.
- [ ] Dùng stream pipeline.
- [ ] Biết khi nào cần child process/worker.

## Express

- [ ] Tạo route CRUD.
- [ ] Viết middleware request id/logger.
- [ ] Validate body trước service.
- [ ] Viết async handler.
- [ ] Viết error middleware.
- [ ] Upload file có giới hạn type/size.
- [ ] Thêm auth middleware.

## NestJS

- [ ] Tạo module/controller/service.
- [ ] Hiểu DI provider.
- [ ] Dùng DTO class và `ValidationPipe`.
- [ ] Dùng `ParseIntPipe`.
- [ ] Viết guard.
- [ ] Viết interceptor response envelope.
- [ ] Viết exception filter.
- [ ] Viết custom decorator `@CurrentUser`.
- [ ] Tích hợp DB.
- [ ] Thêm Swagger, Docker, config validation.
